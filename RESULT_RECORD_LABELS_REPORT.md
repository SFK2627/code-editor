# Step 253 - Result & Feedback Recording Labels

Added clear recording details to the Result & Feedback card.

## What changed

- Shows the student name at the top of the result card.
- Shows the selected activity/rubric name directly under the student name.
- Shows Student ID, section, project name, and checked time when available.
- Includes the same header while the result is checking and if the checker needs retry.
- Saves the same result metadata in generated result objects for project/submission records.
- Updated the service worker cache name so the latest interface appears after deploy.

## Purpose

This makes it easier for the teacher to record scores without guessing which student or activity the result belongs to.
