ICT 8 CONNECT / G8Code — STUDENT HOME DASHBOARD UPDATE (2026-11-01)

WHAT'S NEW
- New separate Student Home dashboard; the original My Projects remains intact.
- Login / first-password-change / student resume opens Student Home behind the existing status modal.
- Closing the login status modal with X or Escape, or selecting its first Continue card,
  returns to Student Home instead of My Projects.
- Academic summary reads current-term published status; numeric/color grade visibility
  and trend follow the existing teacher settings. Unpublished values are not invented.
- Completion/missing counts and up to three actual lacking tasks (or a friendly empty state).
- Mirrored Code Explorer HTML/CSS/JS progress and resume text (existing progress storage).
- Saved project count, recently updated project, and existing teacher feedback.
- Functional quick links to Projects, Lessons, Activities, Code Explorer,
  Recitation, Code Inbox, Mini-Games and Leaderboard.
- Dedicated phone bottom navigation, responsive cards for phone/tablet/desktop,
  smooth subtle animations with prefers-reduced-motion support.
- Theme support for original light/dark and existing teacher-published full-app themes.
- Home navigation on the My Projects header and in the editor's student navigation menus.
- Lessons and Activities return to Student Home when opened from Student Home.
- Code Explorer returns to Student Home when opened from Student Home.
- Existing games, projects, Firestore rules, Apps Script, and admin sections were preserved.
